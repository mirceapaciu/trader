# Feature: Add Redis integration tests

## Problem Statement

The integration suite did not validate Redis availability or stream operations, even though Redis Streams are a core runtime dependency for queue processing.

## Verified Evidence

- Existing integration coverage only validated PostgreSQL.
- No tests in `tests/` exercised Redis connectivity or streams.

## Expected Behavior

Integration test command should execute Redis-backed checks for:

- broker connectivity,
- required stream write/read capability.

## Acceptance Criteria

- Add tests marked with `@pytest.mark.integration`.
- Tests connect to local Redis using documented env defaults.
- Tests validate required stream names can receive events.
- `uv run pytest -m integration` executes Redis integration tests.

## Test Plan

- Start Redis via `scripts/deployment/redis/start.ps1`.
- Run `uv run pytest -m integration -q`.

## Root Cause

Redis integration checks had not yet been implemented.

## Resolution Steps

- Added integration module `tests/integration/test_redis_integration.py`.
- Implemented broker ping validation and stream event append checks.
- Marked test module with `pytest.mark.integration`.

## Remaining Risks / Follow-up

- Add consumer-group integration checks (create/claim/ack flow).
- Add outbox-to-broker end-to-end integration tests once storage adapters are wired.
