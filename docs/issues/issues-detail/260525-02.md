# Feature: Add PostgreSQL integration tests

## Problem Statement

The repository had no integration tests, so `uv run pytest -m integration` did not execute any real validation against infrastructure components.

## Verified Evidence

- The test suite only contained unit tests under `tests/core_components/event_ingestion_engine`.
- Running `uv run pytest -m integration -q` deselected all tests.

## Expected Behavior

Integration test command should execute PostgreSQL-backed checks for:

- successful connectivity,
- expected schema initialization from deployment scripts.

## Acceptance Criteria

- Add integration tests marked with `@pytest.mark.integration`.
- Tests connect to local PostgreSQL using documented env defaults.
- Tests validate required component schemas exist.
- `uv run pytest -m integration` runs these tests.

## Test Plan

- Start PostgreSQL via `scripts/deployment/postgres/start.ps1`.
- Run `uv run pytest -m integration -q`.

## Root Cause

Integration coverage had not yet been implemented for database infrastructure.

## Resolution Steps

- Added integration test module `tests/integration/test_postgres_integration.py`.
- Implemented connectivity check (`SELECT 1`) and schema existence assertion.
- Marked tests as `integration` for command-based selection.

## Remaining Risks / Follow-up

- Add Redis integration tests for queue backend health and stream setup.
- Add component-level integration tests once repositories/services are implemented.
