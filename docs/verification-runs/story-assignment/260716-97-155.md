**New nuance — counterparty entity leakage (CS-0059).** #149: an NVDA-tagged article about
*TSMC's* Arizona investment passed into the *TSMC Q2-results* window on the token `tsmc`. The
entity exclusion strips only the **subject** instrument's name (NVDA), so **counterparty** names
(TSMC, Apple, Nokia) still leak and can match a different-event window that shares that
counterparty. A fix should also exclude prominent counterparty entities, or require a
*distinctive* (non-entity) shared token.
